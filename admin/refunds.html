PAIEMENTS EN LIGNE MERCURE / PAYLINE

Rembourser une réservation

Pour les réservations payées en ligne sur Mercure. Le remboursement est exécuté par Mercure sur la carte du client.

Opération irréversible, protégée en trois étapes.

1. Recherche du rendez-vous dans le planning Mercure (lecture seule). 2. Vérification du récapitulatif, puis nouvelle saisie du numéro et du montant. 3. Code Google Authenticator à usage unique, puis exécution.

Chaque réservation ne peut être remboursée qu’une seule fois depuis ce menu, le montant ne peut pas dépasser ce que Mercure a encaissé, et un plafond quotidien s’applique (—). Le client n’est pas prévenu automatiquement.

Vérification de l’accès…

1. Retrouver le rendez-vous

Le numéro et la date figurent dans le planning Mercure (fiche du rendez-vous).

2. Vérifier et confirmer

La confirmation expire après 5 minutes. Attendez le code suivant si vous venez d’utiliser le code affiché pour vous connecter.
