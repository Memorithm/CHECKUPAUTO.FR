Véhicules & tarifs déclenchés

Chaque véhicule possède sa prestation Mercure et son tarif souhaité. Un tarif différent du tarif Mercure reste visible mais passe automatiquement en réservation par téléphone tant qu’il n’est pas réellement garanti côté Mercure.

Exemple : si « Ambulance » est liée au VASP à 90 € mais que vous saisissez 75 €, CyberCheck n’ouvrira pas une réservation en ligne à 75 € tant que Mercure ne possède pas une promotion/prestation correspondante.

Mode léger recommandé — callback navigateur

Le code source Mercure contient déjà success: function(route) après /add_rendezvous_client_libre. AutoBilan-Systems peut ajouter ce fragment juste avant window.location.href = route. Aucun secret serveur n’est exposé.

const p = new URLSearchParams(window.location.search);
const ccid = p.get('ccid'), cct = p.get('cct');
if (ccid && cct) {
  const body = JSON.stringify({ ccid, cct, route });
  navigator.sendBeacon(
    'https://www.checkupauto.fr/api/integrations/mercure/browser-confirmed',
    new Blob([body], { type: 'text/plain;charset=UTF-8' })
  );
}

Le jeton cct est signé par Checkup Auto et valable uniquement pour l’intention de réservation correspondante. Les répétitions sont dédupliquées.

Webhook de confirmation

À communiquer à AutoBilan-Systems si leur compte Mercure RDV permet un webhook sortant. Le corps JSON est signé avec HMAC-SHA256.

Ne configurez pas définitivement le fournisseur sur l’adresse trycloudflare.com : elle est temporaire.
